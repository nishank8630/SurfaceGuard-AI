# Benchmark Results Directory

Stores experiment tracking runs, metric summaries, and evaluation reports:

- `results/reports/benchmark_summary.csv`: Macro and per-category AUROC, AP, IoU
- `results/reports/benchmark_report.md`: Markdown summary report
- `results/figures/`: Generated ROC curves, PR curves, and anomaly localization overlays
- `results/runs/`: Timestamped raw JSON result logs
