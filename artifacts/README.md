# Artifacts Directory

This directory stores serialized models, feature memory banks, and calibrated thresholds:

- `artifacts/feature_banks/<category>_resnet18_bank.pt`: Feature memory banks for PatchCore
- `artifacts/checkpoints/<category>_autoencoder.pt`: Trained Autoencoder weights
- `artifacts/thresholds/<category>_thresholds.json`: Calibrated decision thresholds
